# ACM AJCE TechTalk Interview

A professional event website developed as part of the **Webmaster Interview Task for the ACM AJCE 2026 Core Team Recruitment Process**.

This project demonstrates proficiency in modern frontend development using HTML, CSS, and JavaScript while emphasizing responsive design, accessibility, performance optimization, maintainable code architecture, and polished user experience.

The website represents a technical event platform featuring event information, speaker highlights, schedules, registration workflows, dynamic theming, and interactive visual elements.

## Overview

The ACM AJCE TechTalk Interview project is a modern event landing page and registration portal designed to simulate a professional technical conference experience.

The project was intentionally developed without frontend frameworks to demonstrate a strong understanding of core web technologies and frontend engineering principles.

Key objectives include:

* Clean and maintainable code structure
* Modern UI and UX implementation
* Responsive design across all devices
* Interactive user engagement
* Performance-focused architecture
* Professional visual presentation

## Features

### User Interface

* Modern glassmorphism-inspired interface
* Gradient lighting effects and visual depth
* Custom typography system using Space Grotesk and Inter
* Smooth hover states and micro-interactions
* Consistent design language across all sections

### Theme Management

* Light mode and dark mode support
* Persistent theme preference using Local Storage
* Smooth transition effects between themes

### Event Experience

* Dedicated hero section
* About section
* Event schedule timeline
* Featured speakers section
* Contact section
* Registration workflow

### Interactive Components

* Animated scroll-based timeline progression
* Dynamic visual feedback
* Animated success modal
* Interactive navigation system
* Custom form controls

### Registration System

* Dedicated registration page
* Form validation
* User-friendly input handling
* Custom dropdown components
* Submission success animations

### Performance & Accessibility

* No frontend frameworks
* Lightweight architecture
* Semantic HTML structure
* Mobile-first responsiveness
* Cross-browser compatibility

## Installation

### Clone the Repository

```bash
git clone https://github.com/edwingeorgeshaji/ACM-AJCE-TechTalk-Interview.git
```

### Navigate to the Project Directory

```bash
cd ACM-AJCE-TechTalk-Interview
```

### Run Locally

#### Method 1

Open:

```text
index.html
```

directly in a web browser.

#### Method 2 (Recommended)

Use Visual Studio Code with the Live Server extension:

```text
Right Click → Open with Live Server
```
